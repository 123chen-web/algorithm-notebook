欧叶OY · 手感试验台

鼠标在卡片上移动、悬停、点击。右上角切换三种安静的底色；背景不动，精致感放在卡片和手感上。

01 弹簧上浮

抬起、变深、回弹

鼠标移上来，卡片像被轻轻托起，阴影同时变深变散；移开时带一点回弹。用的是 CSS 弹簧曲线，不用任何库。

02 聚光灯

光跟着你的鼠标走

边框和卡片内部都被一团光照亮，光点就是鼠标位置。Linear、Vercel 一类产品常用的手法。

03 倾斜 + 反光

像一块有厚度的玻璃

卡片朝着鼠标微微倾斜，表面划过一道光。位置是逐帧追赶的，不会突然跳动。

04 数字与图表
0

条待复习（数字从 0 滚到目标值）

05 磁吸按钮

靠近就被吸过去

鼠标靠近按钮时，按钮和里面的字会朝鼠标轻轻靠拢。

06 列表挪位

点任意一行，它会平滑飞到最前

07 页面切换（原生 View Transitions）

总览页：内容整体淡入并轻轻上浮。

复习页：切换时旧页面淡出、新页面淡入，不会闪一下。

路线页：浏览器原生支持的页面过渡，不需要动画库。

二分查找时，边界该写 < 还是 <= ？

点击翻面看答案

答案

闭区间 [l, r] 用 <=，每次收缩要 ±1；左闭右开 [l, r) 用 <。
