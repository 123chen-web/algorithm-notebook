# 笔记第二轮：功能与界面方案（10/14 定稿）

> 10/14 夜写，10/15 开工前给站长过目。第一轮（自动保存、本机草稿、历史版本、最近删除、画板插图）已上线。
> 对照的产品：Apple 备忘录 / Bear（顺手）、Notion（模板、块）、Obsidian（双链、大纲）、
> RemNote / Obsidian Spaced Repetition（笔记里直接做复习卡）、Excalidraw 图形库。
> 原则：笔记要服务闭环“做错 → 记下 → 重做 → 变强”，不做和闭环无关的花活。

## 一、界面：从“时间线 + 卡片里编辑”改成“列表 + 编辑区”

现在：上面一个新建框，下面一串卡片，点“编辑”在卡片里原地变编辑器。问题：长笔记挤在卡片里、
编辑和浏览来回跳、没有“正在写哪篇”的稳定位置。

改成（桌面 ≥1024px）三栏，和 Bear / Apple 备忘录 / Obsidian 一样：

```
┌ 筛选栏 ─┬ 笔记列表 ────────┬ 编辑区 ─────────────────────────────┐
│ 全部    │ [搜索……]  [+新建]│ 单调栈：下一个更大元素        已保存 21:03 ⋯│
│ 置顶    │ ▸ 单调栈…  10/14 │ #栈  📝 每日温度              目录 ▾      │
│ 关联错题│   两行预览…      │ ──────────────────────────────────────── │
│ 有画板  │ ▸ 二分边界 10/12 │ 正文（最宽 72 字，标题用宋体）            │
│ 标签 ▾  │   …              │                                          │
│ 最近删除│                  │ 输入 / 插入：模板、代码、公式、画板、错题 │
└─────────┴──────────────────┴──────────────────────────────────────────┘
```

- 点列表里一篇就在右边打开，**直接就是可编辑的**（不再有“编辑”按钮），停手自动保存。
- 编辑区顶部：大号标题输入、标签胶囊、关联题目、保存状态；“⋯”菜单里放置顶 / 历史版本 / 导出 / 删除。
- 长笔记右侧可展开“目录”（按标题生成，点击跳转）。
- 手机：列表一屏，点进去编辑区全屏；键盘上方一条工具条（代码、公式、图片、画板、待办、撤销）。
- 新建：列表顶部“+ 新建”下拉选模板；`N` 快捷键；命令面板里也有“新建笔记”。
- 空状态：给 3 个模板按钮，而不是一句“还没有笔记”。

## 二、功能（按对闭环的帮助排序）

### A. 笔记和错题打通（最该做）
1. 错题详情里加“写笔记”：新建一篇已关联这道题的笔记，套“错题复盘”模板。
2. 笔记里输入 `/错题` 嵌入一张**活的错题卡**：显示题名、错因标签、下次复习日期，点开就是这道错题。
3. 错题详情里显示“相关笔记”（反向链接），复习时一眼看到自己写过的总结。

### B. 模板（对标 Notion）
- 套路笔记：触发信号 / 核心思路 / 代码模板 / 易错点 / 例题（链接到学习路线的套路）。
- 错题复盘：题目 / 我当时怎么想的 / 错在哪（错因词表里选）/ 最小反例 / 这次改对的关键。
- 比赛 / 周总结、解法对比（已有）。
- 只给结构和提示语，不替用户写内容（守住“AI 不给标准答案”）。

### C. 笔记里直接做复习卡（对标 RemNote，差异化最大）
- 选中一句话 → “做成复习卡”（问答卡或挖空卡 `{{c1::…}}`），进同一个 FSRS 复习队列，
  复习时显示出处笔记。卡片内容完全由用户自己写。
- 需要新表（迁移 88）和复习页支持“笔记卡”这种类型，工作量最大，建议第二步做。

### D. 写代码更顺手
- 代码块：语言标签、行号、一键复制（编辑器里已经带了语法高亮，只差界面）。
- 代码块里“运行”接现有的代码运行器（有额度限制的沿用原规则）。

### E. 画板更适合画算法图
- 自带“算法图形库”：数组格子、指针箭头、链表结点、二叉树结点、网格、栈/队列，一拖就用
  （Excalidraw 的 library 功能，离线打包，不连外网）。
- 笔记里的画板缩略图点一下就在原地打开编辑。

### F. 找得到、带得走
- 搜索结果显示命中片段并高亮，能搜代码块里的内容。
- 单篇导出 Markdown（图片打包）、打印 / 存 PDF。

## 三、方向调整（10/14 站长）：笔记只做“关联”，不加任务

站长原话：“我的笔记只是相关联更多功能，不是想加重任务。”所以：

- **不做**：笔记复习卡进每日队列、“快忘了 / 今天该看 N 篇笔记”提醒、辨析卡、自测打分。
  每日要做的事只有“今日复习”的错题，笔记不再往里加量。
- **只做关联**（用的时候顺手看到，不需要额外操作）：
  1. 错题详情里“写笔记”：新建一篇已关联这道题的笔记（套“错题复盘”模板）。
  2. 笔记里 `/错题` 嵌入一张活的错题卡：题名、错因、下次复习日，点开就是这道错题。
  3. **复习某道错题时，顺带显示你写过的相关笔记**（关联这题的、链接到这题的、同套路的套路笔记），
     折叠成一行，点开才看。
  4. 套路笔记里自动汇总“我在这个套路上犯过的错”（错因 + 最小反例 + 下次复习日），只是链接。
  5. 学习路线的套路页显示“我的套路笔记”，没有就给一个“用模板写一篇”的入口。
- **可选的查看方式**：“遮住看”——只露出标题和加粗关键词，点一下展开一节；不打分、不排计划。
- 工具类（不加任务）：代码块语言/行号/复制、画板算法图形库、搜索命中片段、单篇导出。
