二分查找的边界总写错，大家是怎么自查的？

最近三道二分题都栽在边界上：有时候死循环，有时候漏掉最后一个元素。

我现在的做法是先写出区间定义，再写循环，但写到 mid 更新那一步还是容易凭感觉改。

想听听大家有没有固定的检查清单，或者能一眼看出区间到底是开还是闭的小技巧。

补充一个检查清单：

  1. 区间是开还是闭，写在注释里；
  2. 循环条件是否和区间一致；
  3. mid 更新后区间是否一定缩小；
  4. 用长度 1、2 的数组各手动走一遍。
