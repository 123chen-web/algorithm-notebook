## 背景与用户的话

用户看腻了现有的水墨背景，想要“流畅、科技感或自然感，鼠标放上去就拎起来那种丝滑的互动”。我们试过会动的背景（极光、星图、等高线、叶影），**用户全部否决，原话：“背景本身太花”**。最终定下的方向：

- **背景完全不动**，只有一块干净的底色（雾白）；
- 精致感全部放在**卡片和控件的手感**上：只有鼠标碰到、手指拖动、点击时才动，平时是安静的。

## 设计原则

1. **安静的底，灵敏的手。** 禁止任何常驻的背景动画、画布、粒子、渐变漂移。唯一允许的“空闲时就在动”的东西：加载骨架的流光。
2. **只动 `transform` / `opacity`**（以及 `grid-template-rows` 做折叠）。不要动 `width/height/top/left`；不要给大列表加 `backdrop-filter`。
3. **每个动效都有“关掉的版本”**：`prefers-reduced-motion: reduce` 下全部改成无动画的即时状态；`(hover: none)`（触屏）下不加悬停特效，只保留点按反馈；页面不可见时暂停所有 rAF。
4. **弹簧曲线用 CSS `linear()`**（试验台里的 `--spring`），外加 `@supports not (transition-timing-function: linear(0, 1))` 回退到 `cubic-bezier(.22,.8,.24,1)`。**不引入任何第三方动画库**（本站严格 CSP、没有构建步骤）。
5. **颜色只用主题变量**，不写死色值（有测试会拦）。**硬规则同前**：严格 CSP（不写行内 `style` 属性、不用 `innerHTML` 拼用户文字、不用 `eval`；用 JS 改 `element.style.setProperty` 是允许的）；测试里不真调 AI/发邮件；不在项目目录建临时目录；改了静态资源同步 `?v=` 和测试里的版本 pin；全量 `PYTHONUTF8=1 python -m pytest tests -q -p no:cacheprovider --ignore=tests/e2e` 全绿（本机 `.claude` 目录引起的 `test_billing_docs_consistency` 误报除外）；前端行为要有测试（参照 `tests/*_behaviour.cjs` + `tests/js_harness.cjs`）。
6. **可访问性**：任何“拖动”必须同时有键盘和按钮的等价操作；翻牌、开关等用正确的 role 和 `aria-*`；焦点环保留可见。
7. **迁移号**：本任务**不需要数据库迁移**（主题偏好存在浏览器本地，沿用现有 `algorithm-notebook-theme`）。

## 第一期：「雾白」主题（`data-theme="fog"`）— **已由 Claude 做完并上线（见 git 历史），Muse 不用做**

（以下保留作设计说明；实际取值见 `static/style.css` 的 `html[data-theme="fog"]`。）

### 要做的
1. **新增第三个主题 `fog`，名字“雾白”**，和“水墨红笔（ink）”“栖间（qixi）”并列。四处主题选择器（`#welcome-theme`、`#topbar-theme`、`#account-theme` 等所有 `[data-theme-select]`）都加这个选项；`static/themes.js` 里两处 `"ink" || "qixi"` 的白名单加上 `"fog"`。**新访客默认雾白**（localStorage 里已有选择的老用户不变）。
2. **令牌**：在 `static/style.css` 里照 `html[data-theme="ink"]` / `qixi` 的写法加一整块 `html[data-theme="fog"]`，**把 `:root` 里每一个会随主题变的令牌都覆盖到**（不要漏，漏的会露出水墨的米黄）。试验台里的取值是起点，可微调但气质要保持：
   - 底 `--paper:#f4f6f8`，卡片/面板 `--surface:#ffffff`，线 `--line:#e3e8ee`，正文 `--ink:#171c22`，次级 `--ink-2:#5b6672`，弱化 `--muted` 取一个对白底≥4.5:1 的灰蓝；
   - 强调色 `--accent:#0e7490`（深青）；`--accent-hover` 更深一档；`--soft` 取强调色的极淡底；
   - `--radius` 家族：卡片 16px、按钮/徽章用胶囊（`--radius-pill`）；
   - **标题字体不用宋体**：fog 下把 `--serif` 指向系统无衬线栈（和正文一致，更干净利落）；`--kai`（“错”字章用的楷体）保持不变，**印章、红笔批改的元素保留**——这是品牌，红色（`--review-pen` 系）在 fog 下仍用红，不跟强调色走；
   - `--series-1..8` 图表色保持原样（它们对白底的对比度已经验证过）；
   - 玻璃/半透明令牌（`--glass-surface`、`--home-surface`、`--record-surface` …）在 fog 下改成**不透明的**接近 `--surface` 的值，因为 fog 没有背景可透。
3. **去掉背景特效**：fog 下 `cursor-fx.js` 的涟漪画布**不创建**（或创建后立刻停掉并移除），`.scene-backdrop` 隐藏，风景选择器 `[data-scene-select]` 的整行隐藏（`themes.js` 里已有“只有 qixi 才显示风景选择”的逻辑，照它扩展）。页面顶部给一抹几乎看不出的淡光（试验台里 `body` 的 `radial-gradient(... rgba(var(--glow), .07) ...)`），用一个新的 `--glow` 令牌（RGB 三元组）实现。
4. **所有页面逐个过一遍**：总览、今日复习、全部记录、新增记录、笔记、画板、学习路线、薄弱点分析、掌握度趋势/热力图、错因专题、成就、周报、小组、讨论区、榜单、账号、套餐、帮助、登录/欢迎页（含介绍片）。重点找：写死的米黄/暖色、白字落在浅底、深色代码块在新底色上的观感、图表颜色、Excalidraw 画板（它有自己的主题，保持浅色）。
5. **对比度**：扩展 `tests/test_contrast_tokens.py`，把 `fog` 加进主题列表，所有文字/背景令牌组合 ≥ 4.5:1（大字、图标 ≥ 3:1），和 ink/qixi 同标准。
6. 欢迎页的主题下拉里文案：`<option value="fog">雾白</option>`。

### 验收
- 三个主题来回切换，页面不闪、没有残留的暖色；
- 刷新后保持选择；新开隐身窗口默认雾白；
- 对比度测试通过；`prefers-reduced-motion` 下没有任何动画。

### 第二期的验收
- 逐项和 `playground.html` 对比手感（弹簧回弹的幅度、聚光灯跟手程度）；
- 三个主题下都好看；手机宽度（375px）不出横向滚动条；
- `prefers-reduced-motion` / `(hover:none)` 两种环境各有测试；
- 性能：在 Chrome 性能面板里悬停、拖动时没有长任务；`feel.js` 静止时 CPU 占用为 0（没有空转的 rAF）；
- 测试：`tests/feel_behaviour.cjs`（聚光灯变量写入、数字滚动的最终值、FLIP 的位置补间、reduced-motion 关闭、静止后 rAF 停止）+ 一个资源版本 pin 测试。
