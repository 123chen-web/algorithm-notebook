# 第三轮需求：栖间版式 + 风景突出 + 控制并入顶栏

接续 round1/round2（均已验收）。本轮只做下面的事，不要扩大范围。
约定同前：遵守 `AGENTS.md`；S1、S2、S3 各自单独提交；全部完成后推送到 `main-lxh6n1`。
参考方向（用户与 GPT 讨论的"栖间"界面截图）：顶部极简导航；左侧大标题 + 一句话 + 主按钮；右侧**一块**毛玻璃面板；风景占满背景；底部/顶部有一个紧凑的"‹ 1/3 场景名 ›"切换胶囊。核心感受：**留白多、不排成一排、不挤成一堆**。

## 现状问题（验收所见）
1. 介绍页的风景大半被左右两张大卡片挡住。
2. 圆点栏（场景名 + 4 个圆点 + 暂停轮播）是独立的一条横条，叠在顶栏下面，像两条横条叠在一起，还把内容往下推。
3. 栖间主题只换了颜色和背景，版式和水墨完全相同。

## S1. 风景是主角（两个主题都适用）
- 介绍页首屏（1280×800、1024×768）里，**不被任何卡片遮挡的风景面积至少占画面 40%**。做法：右侧示例卡缩小（宽度不超过约 360px）并与左侧文案卡错开，不要两张大卡并排占满；<1100px 时示例卡收到文案下方或折叠，不遮风景。
- 手机（390×800）：静态首图 + 轻微涟漪（沿用既定）；文案卡紧凑，示例卡放到首屏以下；首屏能看到至少 35% 的风景。
- 场景图本身不重画，沿用 `static/scenes/` 的四张 SVG；可微调 `background-position`/裁切让主体（山、窗、湖）落在不被遮挡的区域。

## S2. 圆点栏并入顶栏（两个主题都适用）
- 删除独立的场景条。把场景控制做成顶栏右侧的**一个紧凑胶囊**：`‹  1/4 水墨山水  ›` + 一个播放/暂停图标按钮；风格选择器（水墨红笔/栖间）放在它旁边。
- 保留既有可访问性：胶囊是 `role="group"` 并有 `aria-label`（选择风景）；上一张/下一张/暂停都是原生 `button`，有可见焦点；键盘左右键切换仍可用；暂停状态用 `aria-pressed`。
- 窄屏（≤700px）：胶囊缩成"‹ 名称 ›"，播放按钮收进它的右侧；风格选择器折进同一行或头像/设置菜单，**不换成第二行横条**。
- 保留既有 id：`scene-name`、`scene-dots`（可改为内部隐藏的指示或圆点内嵌在胶囊里）、`scene-play`、`scene-backdrop`，既有测试若依赖请同步并列出改动。

## S3. 栖间主题做出真正的版式（仅 `data-theme="qixi"`，水墨主题保持不变）
- **介绍页**：顶栏透明极简（品牌 + S2 的胶囊）；左侧大标题（"让做错的题，成为下次的把握。"）+ 一句话 + 「开始使用」「免注册体验」；右侧只放**一块**毛玻璃面板（把现有"一条值得记住的错误"示例缩成面板，不再有外层粉/绿色大底板）；整体多留白，元素之间间距明显大于水墨主题。
- **学习大厅**：顶部只留极简导航（品牌 + 账号/额度小徽标，沿用 round2 的紧凑做法）；左侧大标题"把薄弱点，练成得分点。"+ 一句话；右侧一块毛玻璃面板放"今日复习"（待复习数 + 进入复习）；其余入口（全部记录、新增记录、薄弱点分析、成就徽章等）放在下方，**两到三列网格、卡片间距加大、不排成一整排**，卡片更小更安静，减少边框和阴影。
- 栖间下的强调色继续跟随场景变化（已实现，保持）。
- `backdrop-filter` 仍只能在 `(hover:hover) and (pointer:fine)` 内；其余用不透明或半透明纯色回退；`color-mix(... transparent)` 必须有 `@supports` 回退。**不要为过测试改测试。**

## 不要做
不动后端/数据库/支付/AI；不新增依赖；不改既有测试（S2 的 id/结构变化除外，需逐条列出）；不在项目目录创建临时/缓存目录；不重画场景 SVG；不加"透明度/模糊/圆角"调节面板（留给以后）。

## 验收（Claude 会逐条核对）
1. 1280×800、1024×768 的介绍页，用像素统计或元素包围盒证明未被遮挡的风景 ≥40%（给出算法与数值）；手机 ≥35%。
2. 没有独立的场景条；胶囊在顶栏内；桌面一行、窄屏不出现第二条横条；键盘（Tab/左右键/空格）和读屏标签可用。
3. 栖间主题下介绍页、大厅的版式与水墨明显不同，符合上面"左大标题 + 右一块面板 + 下方 2–3 列"的描述；水墨主题截图与 round2 相比无意外变化。
4. 两主题 × 1280/1024/800/390/360/320 宽度无横向溢出；大厅标题与第一排入口在 1280×800、390×800 首屏可见。
5. 帧率不退化：重新用有界面浏览器测桌面涟漪空闲/播放/切换，给出前后数据（round2 基线：约 165fps，最长单帧 6.3ms，水墨切换冷峰值 66.6ms）。
6. 全量 `pytest -q` 通过（云端缺支付 SDK/中文字体除外）；既有测试改动逐条列出原因。
7. 最终说明含：改动文件、改过的 id/测试、截图（两主题 × 桌面/手机 × 介绍/大厅）。
