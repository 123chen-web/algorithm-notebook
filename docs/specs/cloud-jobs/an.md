# 任务 AN（分支 `cs/an`）


## 0. 目标与依据
对标笔记结论：
- **Anki 统计 / FSRS**（已核对）：把“记住了多少”拆成可解释的量（稳定性、难度、可提取性），卡片按成熟度分档看占比。
- **Khan Academy**（凭记忆）：掌握度用“尝试过 / 熟悉 / 熟练 / 精通”四档，而不是百分比。
我们的现状：掌握度趋势页（`#mastery-page`，`static/mastery.js`）把 8 个分区的折线叠在一张图里，比较挤；薄弱点分析页与错因专题页给出建议，但“怎么马上练”还要自己去找；专题页看不出有没有改善。目标：让用户一眼看到“哪 1–2 个分区最需要关注”，并能一键练。**不改后端、不加迁移**；只用现有接口的数据。

## 1. 你负责的文件
`static/mastery.js` / `static/mastery.css`、薄弱点分析页与错因专题页的前端渲染（`static/clusters.js` / `static/clusters.css`，以及 `static/app.js` 里薄弱点分析渲染函数——先 `grep` 找全，只改展示部分）、测试。**不要碰**后端、总览（OV）、复习页（RVB / RVF）、论坛、套餐。`FocusReview.start({zone, tag, ids})` 是现成入口（见 `focus.js` 头部注释）：RVF 任务会让它改走 `/api/review/queue`，你只用它的现有参数契约，别改 `focus.js`。

## 2. 掌握度趋势页
- **四档等级**：从每个分区“当前掌握度百分比”（页面已有的数据）映射：`< 40%` 陌生、`40–69%` 熟悉、`70–89%` 熟练、`≥ 90%` 精通（边界写成常量并有测试）；没有数据的分区显示“还没有记录”。
- **总览列表**（默认视图，替换现在叠在一起的 8 条线作为首屏）：每个分区一行：分区色点（`--zone-color`）· 分区名 · 等级胶囊（四档用令牌区分，且**不只靠颜色**：文字 + 阶梯图标）· 一条阶梯进度条（四段，已达到的段点亮）· 当前百分比 · 一个小的迷你走势（沿用页面已有的周数据，12 周，画不出就隐藏）· “有 N 条已到期”（若页面已有该数据）。按“最需要关注”排序（等级低的在前，同级按到期数多的在前）；**前 2 行加“优先”标记**（最多 2 个，且仅当它们的等级为陌生 / 熟悉）。
- **主图**：只画被选中的分区（默认选中“优先”的那 1–2 个；点任意行可加入 / 取消选中，最多同时 4 条；颜色 / 线型沿用现有的分区区分方式），其余不画；保留 75% 参考线（“快被遗忘线”）、“查看数据表”折叠、现有的“有一科快被遗忘了”提示条及其按钮行为。图例就是列表里被选中的行，不再单独放一排芯片。
- 手机：列表单列，主图在列表下方，横向不滚动。

## 3. 薄弱点分析页
每个分区级薄弱项 / 每个 AI 识别出的薄弱模式旁加按钮 **“现在就练 5 条”**：从该分区（或该模式引用的易错点 id，页面已有）当前到期的易错点里取最多 5 条（按到期日升序），调用 `FocusReview.start({ ids })`；没有到期的就把按钮禁用并写“这一块今天没有要复习的”，旁边给“去看看这一块的记录”（跳到“全部记录”并按分区筛选，沿用现有的 `app:navigate` / 筛选机制）。读取到期 id 用现有的 `GET /api/mistakes?due_only=true&zone=…`（别新增接口）。

## 4. 错因专题页
- 每个专题卡片加**“已改善 / 仍在反复 / 样本不足”**徽标，规则（前端用页面已有数据判断，拿不到就整体不显示徽标，别新增接口）：专题成员里最近 14 天内的复习中，`quality < 3` 的占比 与 更早的复习相比；最近 14 天复习不足 3 次 → “样本不足”；占比下降 ≥ 20 个百分点 → “已改善”；上升或持平且仍 ≥ 40% → “仍在反复”；其余不显示。徽标要有文字说明悬停 / 聚焦提示（“最近两周答错的比例 18%，之前是 47%”）。
- 卡片底部加同样的“现在就练这个专题”（成员里到期的最多 5 条，规则同上）。
