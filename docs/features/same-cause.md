## 老毛病：同一个错因，以前也犯过

错题详情的“错因标签”下面，如果你以前在**别的题**里也用过同一个错因标签，会多一行小字：

> 老毛病「边界/特例」：你在《二分查找》、《搜索插入位置》等 5 道题里也是这样错的。

题名可以点，点了直接打开那条易错点。保存标签后立刻刷新，以后再打开这条也会显示。

- 只是把知识串起来：不弹窗、不提醒、不打分、不进复习队列。
- 按**题**算：同一道旧题里有几条同错因的易错点，也只列一次（取最近的那条），数量也按题数。
- 每个错因最多列 3 道，最近的在前，多了显示“等 N 道题”；同一道题里的其他易错点不算；“其他”太笼统，不算。
- 接口：`GET /api/mistakes/{id}/same-cause` → `{groups: [{tag, total, items: [{id, problem_id, title, description}]}]}`，只看本人的数据。

### 汇成笔记

每行老毛病后面有“汇成笔记”按钮：取这个错因下最多 20 道题（`?limit=20`，上限 20），在笔记的新建区放一篇草稿——
标题“我的老毛病：错因名”，每道题一行 `[[题:题名]]：当时写的错因`（当前这道排第一），最后留一节“我的对策”自己写。
只用你自己记过的内容，不用 AI；不点保存就不会留下。题名里的 `[ ] |` 换成空格，免得弄坏链接。

### 我给自己定的对策（10/17）

“汇成笔记”生成的“# 我的老毛病：错因”笔记里，“## 我的对策”那一节写的内容会被串回来（`countermeasures.py` 解析，没改过的占位句“下次看到……，先……”不算；编辑器的转义字符读的时候还原）：

- **复习时**：一条易错点的错因标签有对应的老毛病笔记、并且写了对策，显示错因后会出现“我给自己定的对策”一块（`GET /api/mistakes/{id}/countermeasures`），可以一键打开那篇笔记。
- **考前一页纸**（错因专题页）：自查清单前面多一节“我给自己定的对策”，列出所有写过的对策（`GET /api/countermeasures`）。
- 同一个错因写了好几篇老毛病笔记时，用最近改过的那篇。只看本人数据，删掉的笔记不算。

### 同套路（10/17）

和“老毛病”同一处（错因标签下面）多一行“同套路「套路名」：你还错过《A》、《B》等 N 道题”：这道题标过的每个套路下，
你别的题里的易错点（每道题取最近一条，最多列 4 道，题名可点）。老毛病按错因串，这一行按套路串。接口 `GET /api/mistakes/{id}/same-pattern`，只看本人数据。
