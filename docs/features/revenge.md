# 复仇成功

> 情绪价值应该来自真实的进步：“三周前你在《xxx》上 WA 了，今天一次做对。”

## 定义（阈值请站长确认）

同一条易错点同时满足以下条件时，记一次“复仇成功”：

1. **曾经失败过**：此前至少有一次评分 ≤ 2，或建题时记录的判题类型属于失败类
   （WA / TLE / MLE / RE / CE / 没做出来）；
2. **这次是实测高分**：本次评分 ≥ 4，且复习模式是 `rewrite`（默写）或 `redo`（限时重做）——
   “只回忆”的自评高分不算；
3. **间隔足够长**：首次失败距今 ≥ 7 天；
4. **每条只触发一次**：触发后在 `mistakes.revenge_at` 写标记，再次高分不再重复触发。

待站长确认的阈值：间隔天数（当前 7 天）、成功分数线（当前 ≥ 4）、失败线（当前 ≤ 2）。

## 数据

- `mistakes.revenge_at`（迁移 83）：触发时的评分时间 ISO 字符串；NULL 表示从未触发。
- 评分接口 `POST /api/mistakes/{id}/review` 成功返回里附 `revenge: {...} | null`，
  字段：`mistake_id`、`problem_title`、`first_fail_date`、`verdict`、`mode`、
  `seconds`（重做用时，默写/无数据时为 null）、`days_gap`。
- `GET /api/stats/revenge`：近 30 天的复仇成功列表（题名、首次失败日期、判题类型、
  本次模式与用时、间隔天数），按触发时间倒序。
- 导出（`GET /api/export`）包含 `revenge_at`；注销账号时随易错点级联删除。

## 前端

- 评分成功且 `revenge` 非空时，在现有盖章流程上加盖一枚“雪耻”印 + 一句文案。
- 总览页“本月复仇成功 N 次”小卡，点开列出近 30 天记录，每条可分享。
- 分享图：`GET /api/stats/revenge/share-card?mistake_id=..&hide_title=0/1`，
  纯服务端绘制，只有点“生成分享图”才请求；题名可隐藏（默认显示，预览时可勾选隐藏）。

## 隐私

- 分享图不含用户代码，只含题名、天数、判题类型和产品名。
- 题名可能含个人信息：生成前显示预览，允许隐藏题名后再生成。
