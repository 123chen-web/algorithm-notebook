
## 专注模式

"专注复习"是一个全屏模式：一次只看一张卡，键盘 1–5 直接打分，顶部有
进度条，可以只练某一个分区。它走同一套复习队列接口，支持每日上限；
接口不支持时会自动回退到普通列表。

另有一个"导航专注模式"：开启后侧栏和手机"更多"抽屉只保留学习入口，
总览页收起社区与套餐相关卡片（被收起的页面仍可直接打开）。开关状态按
用户存在本机浏览器，不联网。


## 三大典型失误与考前一页纸

错因专题页顶部有一张"我的三大典型失误"卡：`GET /api/stats/typical` 按错因
标签统计仍未掌握的高频失误，用模板生成提醒文案和清单，不调用 AI。
同一页还有"考前一页纸"打印视图，把三张卡片排成适合打印的一页，考前看一眼。
