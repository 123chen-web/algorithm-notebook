# 私人笔记

笔记支持 Markdown 子集、最多 10 个标签、标题/正文搜索、标签筛选、置顶、编辑和软删除；每账号最多 2000 条，包含软删除记录，正文最多 20000 字。页面和题目详情均有入口，只能关联本人题目。

`GET/POST /api/notes`、`GET/PUT/DELETE /api/notes/{id}`。更新没传 `problem_id` 保留关联，显式传 `null` 解除关联。删题后关联自动置空。正文用 DOM API 和 `textContent` 创建节点，只允许 http/https 链接，外链带 `rel=noopener`；HTML、脚本和属性按文本显示。

JSON「导出我的数据」包含笔记标题、正文、标签、关联题目标题、置顶状态与创建/更新/软删除时间。账号注销删除该账号全部笔记，含软删除记录。笔记不公开给其他用户。
