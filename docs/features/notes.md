# 私人笔记

笔记是私人的，只有本人能看到。新建和编辑用所见即所得编辑器（Tiptap 离线打包，文件在
`static/vendor/editor/`）：输入 `/` 选择标题、列表、待办、代码块、行内/整行公式、表格、分割线、
图片、链接到笔记、链接到错题、画板；选中文字出现浮动工具栏；输入 `[[` 联想另一篇笔记或错题。
数据库里仍保存 Markdown 文本（`notes.content`），所以搜索、导出、笔记链接都按 Markdown 处理。
编辑器脚本加载失败时自动退回普通输入框，保证笔记永远能写。

- 标签最多 10 个，支持标题/正文搜索、标签筛选、置顶、编辑和软删除；每账号最多 2000 条。
- 公式：`$行内$`、`$$整行$$`，用 MathML 渲染（不需要行内样式，兼容严格 CSP）。
- 图片：粘贴或拖入，保存为 `![](attachment:ID)`，只读取自己的附件；单张 ≤3MB，每人 ≤100MB。
- 链接：`[[笔记标题]]`、`[[题:题目标题]]`、`[[标题|别名]]`；每条笔记有“关联”折叠区（引用了谁、被谁引用）
  和关系图（只看自己的笔记）。
- 画板：见[画板](#画板)；笔记里用 `![标题](drawing:ID)` 引用，显示缩略图。
- 流程图（mermaid）在严格 CSP 下无法渲染，显示为原文代码块。

## 不丢字：自动保存、本机草稿、历史版本、最近删除

和 Notion / Apple 备忘录 / Google 文档一样，写了就不用再操心“有没有保存”（`static/notes-history.js`）：

- **自动保存**：编辑已有笔记时，停手 1.5 秒自动保存（Ctrl/⌘+S 立即保存），编辑区下方显示
  “已自动保存 21:03 / 正在保存… / 没保存上”。按钮只剩“完成”和“放弃本次修改”；放弃会把打开时的
  内容写回去，改过的内容先存进历史，所以也能反悔。
- **保存冲突**：每次保存都带上 `base_updated_at`（打开时看到的版本）。别的窗口或设备改过时返回 409，
  编辑区给两个选择：“保留我的（对方版本存进历史）”或“看最新的（放弃我这次的改动）”，不会悄悄覆盖。
- **本机草稿**：新建区和编辑中的内容随手存在本机（`localStorage`，按用户 id 分开）。断网、关页面、
  浏览器崩溃后再进笔记页会放回去；编辑时若有一份对得上版本的未保存修改，会提示“恢复它 / 不要了”。
  有未保存的改动时关页面会先尝试保存并提醒。存储不可用时静默降级，服务器保存不受影响。
- **历史版本**（迁移 87，`note_revisions`）：每次改正文/标题/标签前存一份“改之前”的样子；
  自动保存很频繁，所以同一条笔记 10 分钟内只留最早那份，每条最多 50 份。笔记卡片“历史”按钮打开
  对话框：左边版本列表、右边渲染预览、“恢复这个版本”（恢复前当前内容也会先存一份）。
- **最近删除**：删除仍是软删除；笔记页右上角“最近删除”列出删掉的笔记，可以恢复（别的笔记指向它的
  `[[链接]]` 会重新接上）或彻底删除（连同历史版本）。

接口：`GET /api/notes/{id}/revisions`、`GET /api/notes/{id}/revisions/{rid}`、
`POST /api/notes/{id}/revisions/{rid}/restore`、`GET /api/notes/trash`、`POST /api/notes/{id}/restore`、
`DELETE /api/notes/{id}/purge`；`PUT /api/notes/{id}` 新增可选字段 `base_updated_at`（版本不符 409）
和 `snapshot`（为真时不管 10 分钟规则，先存一份历史）。导出里每条笔记带 `revisions`。

## 接口

`GET/POST /api/notes`、`GET/PUT/DELETE /api/notes/{id}`。更新没传 `problem_id` 保留关联，
显式传 `null` 解除关联。`GET /api/notes/{id}/links`、`/api/notes/suggest`、`/api/notes/graph` 提供链接、
联想和关系图；`POST /api/notes/attachments` 上传图片；`/api/drawings` 系列管理画板。所有接口只处理本人数据，
别人的资源一律 404。

## 画板

自托管的 Excalidraw，页面在 `/static/draw/`，与笔记页同源 iframe 嵌入，通过 postMessage 通信，不访问外部服务。
场景数据保存在数据库（≤2MB，≤5000 个元素，每人 ≤50 张），缩略图保存在数据目录。

**插图片**：工具栏的图片按钮、直接粘贴或拖进来都行（面板栏有提示）。画板页的 CSP 只对 `img-src`
多放行了 `data:`——Excalidraw 用 data: 地址画图片和自己的图标，之前没放行时插入的图片一律是坏图。
图片不再塞进 2MB 的场景里：保存前宿主把 PNG/JPEG/WebP/GIF 传成笔记附件（单张 ≤3MB、每人共 ≤100MB，
服务器重新编码并去掉 EXIF），场景里只留 `attachment:ID`；打开时再取回来还原。传不上就照旧内嵌。
画板、回收站里的笔记和历史版本引用的附件都不会被“孤儿清理”删掉；导出的画板带附件清单。
带照片的缩略图超过 300KB 时，宿主先在浏览器里逐级缩小再上传。仅对 `/static/draw/`
路径放宽安全头（允许同源嵌入、两段固定内联块按哈希放行），全站没有放宽 `unsafe-inline` / `unsafe-eval`。

## 导出、备份与注销

JSON「导出我的数据」包含笔记标题、正文、标签、关联题目标题、置顶状态、创建/更新/软删除时间，
以及链接关系、附件清单（不含图片内容）和画板场景。备份（`backup.py`）会把笔记图片和画板缩略图一起打包。
账号注销会删除笔记、链接、附件文件和画板。
