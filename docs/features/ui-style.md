
## 界面风格

未登录默认进入 `#/welcome` 产品介绍页，点击「开始使用」进入独立的 `#/auth`。
登录和注册通过页内标签切换，找回/重置密码与免注册体验沿用现有接口。
首次加载先检查会话，已有登录状态直接显示学习大厅。

`static/scenes/` 中的四张风景为本项目原创 SVG，无远程图片或额外依赖。
场景由 `static/scenes.js` 中唯一的 `SCENES` 数组（id/name/src/accent）配置，
以后使用已授权照片只需替换这个数组。桌面约每 9 秒淡入淡出，可以暂停、
点圆点或用左右键切换；手机静态显示首图，支持点选和横向滑动。
减少动效偏好下不自动轮播，页面隐藏或离开介绍页时停止轮播。

介绍页右上角和登录后的头像菜单可选择「水墨红笔」（`ink`）或「栖间」（`qixi`）。
主题通过 CSS 变量即时切换，选择存入 localStorage，存储不可用时默认水墨。
栖间可在头像菜单换风景，强调色随场景变化；桌面支持毛玻璃面板，
触屏及不支持模糊的设备使用纯色面板。主题不触发刷新或重播开场动画。

视觉方向为「红笔批改 × 水墨」：水墨山水作为背景，宣纸和墨色承载内容，
朱砂红笔圈注、下划线和印章提供识别点。大胆只用在红笔和印章，其余保持克制。
今日复习用墨色主卡建立层级，其他卡片使用统一浅底和细边框，强调色只用于图标、
小字及必要的操作。首页在视口宽度至少 781px 时，主卡跨两行，右侧的「全部记录」和
「新增记录」各占半幅，以上下两张横条排列；手机保留原有排布。

色板集中定义在 `static/style.css` 的 `:root` 中：

| --- | --- | --- |
| `--paper` | 宣纸，页面底色 | `#f5f0e6` |
| `--paper-2` | 浅宣纸，稿纸和浅底 | `#fbf8f0` |
| `--surface` | 卡片底 | `#ffffff` |

标题使用系统衬线字体令牌 `--serif`：
`"Times New Roman","Songti SC","Noto Serif SC","Source Han Serif SC","STSong","SimSun",serif`，
拉丁字母和数字优先使用 Times，汉字使用宋体，标题字重为 500。
印章和红笔批注使用楷体令牌 `--kai`：
`"KaiTi","STKaiti","Kaiti SC","Songti SC",serif`。
正文、按钮、表单及表格继续使用现有系统无衬线字体栈；不加载外部字体、图片或 CDN。

新增页面应引用这些令牌，不要再硬编码颜色。山水特效开关、半透明宣纸面板机制、
触屏处理和无障碍行为保持现有规则。

### 排版与版面

文字排版沿用 15px 正文基准，字号梯度为 12 / 13 / 15 / 18 / 22 / 26 / 32px，
分别对应 `--text-xs` 至 `--text-3xl`。按钮、标签、表单和导航使用
`--lh-ui: 1.5`，连续说明文字使用 `--lh-prose: 1.85`，标题使用
`--lh-heading: 1.3`；大标题的行高比例更紧，长段文字保留较宽松的阅读节奏。
间距统一采用 4px 的倍数：`--space-1` 至 `--space-8` 分别为
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px。

长段说明使用 `--measure: 38em` 控制阅读宽度，约为 38～40 个汉字；
宽度限制作用于文字块，面板仍占满所在网格。各视图页标题左边线对齐页头网格，
不再通过整页缩窄居中控制行长。记录列表采用同一宣纸面板内的分隔行；
新增记录在桌面上按「左侧分区说明、右侧字段」排布，在窄屏上回到单列。

页头与首页用户卡使用头像菜单收纳更换或移除头像、数据导出和山水涟漪开关，
支持 Tab 导航及 Enter/Space 触发，Escape 关闭并将焦点还给头像入口，点击外部或完成菜单操作后关闭。
介绍页下半部分将三步说明整合为带分隔线的一块宣纸面板，并将差异说明与内测提示合为另一块，桌面分栏、手机单列。

中文排版使用渐进增强属性：`text-autospace: normal` 在中文与西文、数字之间
自动留出间距，`text-spacing-trim: normal` 处理中文标点间距，
`line-break: strict` 采用严格的中文断行规则。段落和提示使用
`text-wrap: pretty` 改善末行和断行，标题使用 `text-wrap: balance` 平衡多行长度。
浏览器不支持这些属性时会忽略对应声明，继续使用原生间距和断行；
现有手写空格、内容及操作不受影响。

参考仓库：`ant-design/ant-design`（设计令牌与字号、间距尺度）、
`w3c/clreq`（中文排版需求）、`anthropics/skills` 中的 `frontend-design` skill
（阅读行长、信息结构与密集列表）。

### 动效与盖章

每次页面加载只有介绍页和首页各一段开场，并且各自最多播放一次；页面不可见或
系统要求减少动态效果时不播放。介绍页依次展开标题墨迹、示例稿纸、红笔波浪线、
批注和「今日到期」印章；首页展开用户名，只有待复习数量大于零时才显示并描画红笔圆圈。
除站点原有的轻微内容淡入外，不给普通卡片和其他区块新增入场动画；主卡的朱砂聚光只在允许动效的桌面细指针设备上跟随鼠标。

保存记录成功盖朱砂「已录」章；复习评分成功按 0 / 3 / 4 / 5 分分别盖
「再练」/「过关」/「记住」/「掌握」章；成就新点亮时盖藤黄「达成」章。
落章时调用 `window.CursorFX.drop(x, y, 1.1)`，在视口坐标处泛起一滴涟漪。
这些印章只作装饰，读屏反馈继续由现有状态消息提供。

`localStorage["achievementsSeen:<用户id>"]` 保存该用户上次查看成就时已经解锁的
徽章 `key` 数组（例如 `streak_3`）。首次查看只建立记录，不盖章；之后只为新增徽章
依次反馈，单次最多三枚，间隔 400ms，切换视图会取消尚未播放的反馈。
本地存储不可用时静默跳过成就盖章，不影响成就内容。

`prefers-reduced-motion: reduce` 下关闭开场、描画、聚光及涟漪，页面内容直接完整可见；
保存、评分或成就反馈改为显示约 1.2 秒的静态印章。视图加载后无需等待开场动画即可使用。


## 鼠标特效

全站统一使用水墨山水涟漪（RippleDistortion），包括未登录的介绍、登录页面、
学习大厅和所有登录后的页面。山水纹理由程序生成，无外部图片、远程资源或额外依赖。
桌面端随鼠标轨迹和点击产生涟漪；触屏端保留点按、拖动涟漪，并在进入页面后
约 0.7–1.3 秒落下首滴微涟漪，之后每隔 4.5–8 秒在随机位置轻轻落下一滴。
自动水滴优先落在露出山水的位置，完全被面板盖住时跳过这一滴。
连续 60 秒没有点按、触摸、键盘或滚动输入时，自动微涟漪停止；再次操作后恢复。
自动水滴只用于无悬停或粗指针设备，桌面端不会自动落点。

介绍页底部和登录后的顶部头像区各有一个「山水涟漪：开/关」按钮，两处状态同步，
支持键盘操作，并通过 `aria-pressed` 发布开关状态。偏好保存在当前浏览器的
`localStorage.cursorFx`（`off` 表示关闭）；本地存储不可用时默认开启。
系统启用 `prefers-reduced-motion`（减少动态效果）时自动关闭，并实时响应设置变化。
WebGL2 不可用或图形上下文丢失时，自动回退到普通、不透明的页面。
画布不接收指针事件，不影响点击、输入或选择文字；切换页面时山水常驻。

特效实际运行时，直接位于山水背景上的外层面板使用原色半透明背景，内部按钮、
输入框、代码块等控件保持原样。桌面细指针设备添加轻微背景模糊；触屏面板提高至
92% 不透明度，且不使用 `backdrop-filter`，减轻持续变化的背景带来的绘制开销。
不支持 `color-mix()`、关闭特效或自动回退时，保留原来的不透明样式。

性能保护：1600×1000 山水纹理以固定种子在离屏 2D canvas 中生成并缓存，
按需提亮至线性相对亮度均值至少 0.82；提亮采用 256 项通道查表，结果与逐像素计算一致。
首次初始化推迟到页面首帧绘制之后。原生 WebGL2 实例化绘制最多 100 个波，
每个波自带多层同心环，位移场默认为 CSS 尺寸的 0.7 倍。
只在有涟漪时持续渲染，调整尺寸、恢复及波纹消失时按需绘制静态山水，随后停止动画循环。
波纹低于 `RIPPLE_MIN_OPACITY` 后停止渲染，减少尾巴上的空转。
页面隐藏时暂停渲染和自动水滴调度，显示后恢复；关闭时释放图形资源、定时器和监听器。
桌面 DPR 上限为 1.5，触屏上限为 1.25；触屏相邻绘制帧至少间隔 12ms，
使 120Hz 屏幕约封顶 60fps，波纹仍按真实时间演化。画布尺寸和触点坐标取自实际边界，
适应手机地址栏伸缩。

可调参数集中在 `static/cursor-fx.js` 顶部的 `RIPPLE_*` 常量：

- 波纹形态：`RIPPLE_BRUSH_SIZE`、`RIPPLE_STRENGTH`、`RIPPLE_SWIRL`、`RIPPLE_RINGS`、
  `RIPPLE_SPREAD`、`RIPPLE_FADE`、`RIPPLE_SPACING`、`RIPPLE_CLICK_STRENGTH`、
  `RIPPLE_START_SCALE`、`RIPPLE_LIFE_CONSTANT`。
- 渲染截断：`RIPPLE_MIN_OPACITY` 是停止绘制不可见波纹尾巴的不透明度下限。
- 色彩与反光：`RIPPLE_DISPERSION`、`RIPPLE_GRAYSCALE`、`RIPPLE_TINT`、
  `RIPPLE_TINT_AMOUNT`、`RIPPLE_GLINT`、`RIPPLE_HIGHLIGHT`。
- 画质与纹理：`RIPPLE_QUALITY`、`RIPPLE_QUALITY_SCALE`、`RIPPLE_MAX_WAVES`、
  `RIPPLE_MAX_DPR`、`RIPPLE_TEXTURE_WIDTH`、`RIPPLE_TEXTURE_HEIGHT`、
  `RIPPLE_TEXTURE_SEED`、`RIPPLE_MIN_LUMINANCE`。
- 自动微涟漪：`RIPPLE_AMBIENT_FIRST_DELAY`（首滴延迟，ms）、
  `RIPPLE_AMBIENT_INTERVAL`（两滴间隔，ms）、`RIPPLE_AMBIENT_POWER`（相对普通涟漪的大小）、
  `RIPPLE_AMBIENT_OPACITY`（起始强度，位移与其平方成正比）、
  `RIPPLE_AMBIENT_MARGIN`（离视口边缘的比例）、`RIPPLE_AMBIENT_IDLE_MS`（无输入停用时间，ms）。
  `RIPPLE_AMBIENT_PROBES` 是每滴自动水滴寻找露出山水位置的候选点数量上限。
- 触屏保护：`RIPPLE_TOUCH_MAX_DPR`（DPR 上限）、`RIPPLE_TOUCH_MIN_FRAME_MS`（最短绘制间隔，ms）。

`window.CursorFX.getState()` 可查看实际模式、目标模式、用户开关及停用原因；
管理器仅接受 `ripple` / `off` 模式。`window.CursorFX.drop(x, y, power = 1.1, opacity = 1)`
可在视口坐标处落一滴涟漪，成功返回 `true`；特效关闭、暂停、页面隐藏或减少动态效果时静默返回 `false`。
已停止空闲绘制的山水仍能接收水滴并唤醒绘制，且不会改变鼠标轨迹的上一落点。
