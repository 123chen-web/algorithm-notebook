# AI 有用/没用反馈

目的：先收集用户对 AI 回答的真实反馈，再决定怎么调提示词。

## 收什么

只收布尔值，不收自由文本：

- 变体题卡片底部：“这道题对你有帮助吗？”→ 有用 / 没用（关联变体题 id）
- 小黄鸭总结后：同样一行（不关联具体题目）
- 薄弱点分析：预留 kind，界面暂未接入

变体题再次点击同一项就是改票（覆盖上一次）；小黄鸭、薄弱点分析每次回答各记一条（界面在同一次回答后只能点一次）。

## 存哪

`ai_feedback` 表（迁移 74）：变体题按 `(user_id, kind, ref_id)` 改票；`kind` 只允许
`variant` / `duck` / `weakness`；`variant` 的 `ref_id` 是变体题 id，
`duck` / `weakness` 的 `ref_id` 为空。

## 隐私

- 它不是用户内容：**数据导出不含此表**。
- 账号注销时随账号一并删除（`delete_account_data`）。
- 隐私政策里有说明：“AI 回答的有用/没用反馈（不含文字）”。
- 管理后台的 AI 指标里有按 kind 的汇总（近 7 天有用/没用数 + 累计）。

## 接口

`POST /api/ai-feedback`，请求 `{kind, ref_id|null, useful}`，返回 `{ok:true}`。
要登录、要 CSRF 头；每用户每小时限 120 次。
