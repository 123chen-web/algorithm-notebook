
## 导出我的数据

JSON 导出另含私人笔记（包括软删除记录）的标题、正文、标签、关联题目标题、置顶与各时间字段，见[私人笔记](notes.md)。

登录后点击页面顶部用户信息卡片里的「导出我的数据」，即可下载 UTF-8 编码的
JSON 文件（`GET /api/export`）。所有套餐及体验账号均可使用；只读现有数据，
不调用 AI，不检查或消耗 AI 额度。

导出只包含当前用户的学习笔记本，按「题目 → 易错点 → 复习记录 / 变式题」
嵌套组织，保留题目代码与思路、易错点与复习进度、复习评分，以及变式题的
模型、作答、预期答案、结果和备注；复习记录和变式题分别按复习时间、创建
时间升序排列。顶层包含用户名和 UTC 导出时间，文件名包含用户名及用户
所在时区的导出日期；没有学习记录时，`problems` 是空列表。

不包含密码哈希、邮箱、时区、会话令牌等账号信息，也不包含订单、套餐、
支付记录、AI 用量、论坛帖子或其他用户的数据。此功能仅导出 JSON，
不会删除账号或学习内容。


## 导出到 Anki

在头像菜单「导出我的数据」旁边可以把错题导出成 Anki 可直接导入的制表符
文本（`GET /api/export/anki`），下载文件名为 `oy-anki-YYYYMMDD.txt`
（日期取服务器 UTC）。范围可选：

- `all`：全部未删除记录（默认）；
- `weak`：还没掌握的易错点，判定与掌握度报告一致
  （单条保持率低于 `mastery.AT_RISK_BELOW`）；
- `mastered`：已经掌握的易错点；
- `zone`：只导出指定分区，必须带 `zone` 参数。

每条易错点一张卡片：正面是题名与分区，背面包含题目链接、错因、当时的
思路、错误代码、最近一次做对的变式代码和错因标签。文件头声明
`#separator:tab` 与 `#html:true`，第一列是稳定 GUID（`oy-<易错点id>`），
重复导入同一个文件不会产生重复卡片。导入 Anki 时保持 Tab 分隔、勾选
允许 HTML 即可。

该接口只读数据、不调用 AI；需要登录，体验账号不可用；每用户每小时最多
导出 10 次（超出返回 429）；单次最多 5000 条，超出返回 413 并提示按分区
导出。思路里以“题目链接：”开头的行，只有其中的 http(s) 链接会进入
卡片正面，其它协议（如 `javascript:`）会被丢弃。
